# RAM Altman vs PC — шуточный пранк-«вирус» для урока информатики

## Что это

Два независимых артефакта:

1. **`Altman_RAM_interview.mp4`** — обычный медиафайл. Первые 9 секунд идёт реальное интервью
   с русской озвучкой, потом «перехват трансляции»: Сэм объявляет, что забирает оперативку.
   Ничего не запускает, открывается любым плеером.
2. **`RAM_Altman_vs_PC.exe`** — «служба оптимизации». Сидит в автозагрузке, ждёт, пока
   видео откроют и **закроют**, после чего показывает системное уведомление. Дальше — игра
   поверх рабочего стола.

## Установка (один раз, на своём ПК или на ПК для показа)

1. Положить рядом в одну папку:
   - `RAM_Altman_vs_PC.exe`
   - `Altman_RAM_interview.mp4`
2. Запустить `RAM_Altman_vs_PC.exe --install` (двойным щелчком с параметром или из командной
   строки). Что произойдёт:
   - видео скопируется на рабочий стол как **«Сэм Альтман — интервью.mp4»**;
   - exe скопируется в `%LOCALAPPDATA%\OpenAI_AGI_Service\`;
   - в автозагрузку (`HKCU\...\Run`) добавится `RAM_Altman_vs_PC.exe --watch`;
   - служба-наблюдатель запустится сразу.
3. Показать на уроке: открыть видео с рабочего стола, дать доиграть, закрыть плеер.

Через ~1–2 секунды после закрытия плеера выскочит уведомление **«Служба оптимизации OpenAI AGI»**.

## Сценарий

| Шаг | Что происходит |
|---|---|
| Уведомление | Кнопки «Да, во имя AGI» / «Нет, это моя память!» |
| «Да» | Полноэкранный плакат «СПАСИБО ЗА ВКЛАД!» со звуком. Сам не закрывается — держать **A + G + I** |
| «Нет» (1-е наведение) | Кнопка отпрыгивает со звуком |
| «Нет» (2-е наведение) | Кнопка уменьшается |
| «Нет» (3-е наведение) | Кнопка становится крошечной внизу справа — клик по ней запускает бой |
| Раунд 1 | Все окна рабочего стола сворачиваются, поверх обоев открывается арена. Слева системный блок (180 HP), справа Сэм (180 HP), таймер раунда 90 с |
| Управление | `A/D` или `←/→` — ходьба, `W` — прыжок, `Пробел` — удар (в воздухе — удар сверху), удержание `Пробела` 0.6 с — выстрел винтами, `S` или `↓` — отскок с неуязвимостью, `F` — «50 вкладок Chrome» |
| Атака Сэма | Шары с логотипом ChatGPT катятся по полу — их надо перепрыгивать. Сэм тоже подпрыгивает через свои шары |
| Фазы Сэма | 100 % / 66 % / 33 % HP: быстрее, новые атаки (лазер, «призыв инвестора», телепорт, серверный шквал), другая аура |
| Подлянка | Когда у Сэма ≤ 25 HP, он вызывает серверную стойку H100, она падает на ПК: 9999 урона |
| BSOD | Настоящий синий экран Windows 11: смайлик, абзац, счётчик «N % завершено», QR-код, код остановки. Подсказок на экране нет — реванш вызывается удержанием **A + G + I** |
| Раунд 2 | Когда Сэм снова зовёт стойку, мигает «ЖМИ ПРОБЕЛ ДЛЯ УВОРОТА!». Успел — стойка падает мимо, комбо «PascalABC.NET Fatal Crash!», FATALITY! RAM IS SECURED! |
| Победа | Плашка ОЗУ возвращается, счётчик 33 ГБ, кнопка «ВЫХОД» |

**Выход из игры в любой момент: `Esc` или `Ctrl+Q`.**

## Удаление

`RAM_Altman_vs_PC.exe --uninstall` — убирает запись из автозагрузки и конфиг.
Второй способ: Параметры → Приложения → Автозагрузка → «OpenAI AGI Optimization Service» → отключить.
Файлы: `%LOCALAPPDATA%\OpenAI_AGI_Service\`, видео на рабочем столе — удалить вручную.

## Важно

- Всё локально, без сети: никуда не стучится, ничего не удаляет, ОЗУ, разумеется, не трогает.
- Пранк виден только на этом ПК и только после установки. Ничего не прописывается в систему,
  кроме одной строки автозагрузки в профиле текущего пользователя (HKCU, без прав администратора).
- Если закрыть видео через «сохранить/открыть другое» — служба всё равно сработает: она следит
  за самим файлом (Restart Manager), а не за окном плеера.

## Сборка из исходников

```powershell
pip install pygame pillow pyinstaller
python tools\build_assets.py        # спрайты, звуки, фоны
python tools\build_video.py         # MP4-вброс (нужен ffmpeg)
python -m PyInstaller --onefile --noconsole --name RAM_Altman_vs_PC --icon icon.ico ^
    --add-data "assets;assets" --add-data "icon.ico;." main.py
```

Файлы проекта:

```
ram_altman_game/
├─ main.py                  вся логика: уведомление, бой, BSOD, победа, служба
├─ assets/                  спрайты, звуки, озвучка (всё генерируется офлайн)
├─ out/Altman_RAM_interview.mp4
├─ tools/                   генераторы ассетов и видео
└─ dist/RAM_Altman_vs_PC.exe
```
