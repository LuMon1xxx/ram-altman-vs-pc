# ПРОМТ ДЛЯ GEMINI (Google AI Studio) — копировать целиком

Ты — Senior Python/Pygame разработчик и гейм-дизайнер. Перед тобой полный исходник
шуточной 2D-игры-пранка **«RAM Altman vs PC»** для Windows, которую показывают на уроке
информатики. Твоя задача — **улучшить геймплей боя**, не сломав уже работающий сценарий,
сборку и «системную» часть.

## 1. Что уже есть (не ломать)

**Стек:** Python 3.10+, pygame 2.6, Pillow, numpy (только для генерации ассетов).
Сборка: `pyinstaller --onefile --noconsole --name RAM_Altman_vs_PC --icon icon.ico
--add-data "assets;assets" --add-data "icon.ico;." main.py`.
Критично: **всё должно остаться одним exe без внешних зависимостей и без сети.**

**Сценарий целиком:**

1. `out/Altman_RAM_interview.mp4` — обычный медиафайл-«вброс» (реальное интервью с русской
   озвучкой, затем «перехват трансляции» и речь Сэма про экспроприацию ОЗУ). Код игры его
   не показывает — это отдельный файл, который открывает пользователь.
2. exe в режиме `--watch` сидит в автозагрузке (HKCU\...\Run), ждёт, пока этот mp4 откроют
   **и закроют** (проверка через Windows Restart Manager + заголовки окон), после чего
   запускает `--game`.
3. **Уведомление** «Служба оптимизации OpenAI AGI» — безрамочное topmost-окно pygame
   (`ToastScreen`), стилизованное под тост Windows 10, с цветовым ключом для скруглённых углов.
   Кнопки: «Да, во имя AGI» → экран благодарности; «Нет, это моя память!» → при первом
   наведении отпрыгивает, при втором уменьшается, при третьем клик запускает бой.
4. **Экран благодарности** (`ThanksScreen`) — полноэкранный плакат, закрывается только
   удержанием **A + G + I**.
5. **Раунд 1** (`FightScreen(round_no=1)`) — арена поверх скриншота рабочего стола
   (полупрозрачный оверлей, topmost). Слева системный блок ПК со 100 HP, справа Сэм Альтман.
   Управление: `←/→` или `A/D` — ходьба, `Пробел` — удар, `F` — спецприём «50 вкладок Chrome».
   Сэм кидает монеты `$20`, бьёт «паяльником», вызывает лазер выпайки.
   Скриптовая подлянка: когда у Сэма ≤ 25 HP — «ВЫЗЫВАЮ СЕРВЕРНУЮ СТОЙКУ!», падает шкаф
   H100, 9999 урона, игрок гарантированно проигрывает.
6. **BSOD** (`BSODScreen`) — аутентичный синий экран Windows 10/11. `Пробел` → реванш.
7. **Раунд 2** (`FightScreen(round_no=2)`) — снова бой, но когда Сэм зовёт стойку, мигает
   «ЖМИ ПРОБЕЛ ДЛЯ УВОРОТА!»; успел — стойка падает мимо, комбо «PascalABC.NET Fatal Crash!»,
   «FATALITY! RAM IS SECURED!».
8. **Победа** (`VictoryScreen`) — плашка ОЗУ возвращается, счётчик 33 ГБ, кнопка «ВЫХОД».
9. **Выход в любой момент: `Esc` или `Ctrl+Q`** (`poll_quit` → `QuitGame`). Это обязательное
   требование, не убирай.

## 2. Что нужно сделать

### 2.1. Бой должен длиться дольше и быть интереснее
Сейчас бой заканчивается за 20–30 секунд и сводится к «подошёл — бей». Нужно:
- увеличить живучесть: HP 100 → 160–200 у обоих (или 3 раунда по 60 секунд с таймером);
- добавить **таймер раунда** на HUD и правило «по таймеру выигрывает тот, у кого больше HP»;
- дать Сэму больше агрессии и телеграфов (wind-up), чтобы бой читался;
- добавить **блок/уклонение** и **отскок** (backdash), чтобы игрок мог реагировать;
- добавить **комбо-систему**: серия ударов множит урон, счётчик «N HITS» уже есть — развить;
- сделать **разные дистанции**: у Сэма и ПК должны быть дальнобойные и ближние опции,
  чтобы игрок выбирал, а не спамил одну кнопку;
- добавить **фазы**: на 66% и 33% HP Сэм усиливается (быстрее, новые атаки, другой цвет ауры),
  с репликой-телеграфом.
Целевая длительность: **60–90 секунд активного боя** до скриптовой подлянки, а не 20.

### 2.2. Новые атаки
Игроку (системный блок):
- **Прыжок на `W`** (и `↑`): физика с гравитацией, приземление с пылью. Прыжок должен
  уходить от низких снарядов — это ключевая механика новой атаки Сэма (см. ниже).
- **Удар сверху** (`Пробел` в воздухе) — «Удар корпусом с высоты», больше урона, но с задержкой
  приземления.
- **Отскок** (`S` или `↓`) — короткий рывок назад с неуязвимостью 0.2 с.
- **Спецприём** `F` оставить («50 вкладок Google Chrome»), но добавить кулдаун-индикатор
  и сделать так, чтобы вкладки реально падали на Сэма и наносили урон по площади.
- **Заряженный удар**: удержание `Пробела` 0.6 с → «Выстрел винтами» (снаряд вперёд).

Сэму:
- **НОВАЯ АТАКА (обязательно): «Шары-логотипы ChatGPT».** Сэм выпускает с правого края
  экрана несколько крупных шаров с логотипом OpenAI (`assets/logo_white.png` /
  `assets/logo_green.png` на круглой подложке; сырьё — `source_media/chatgpt_logo.png`),
  они катятся по полу слева направо на **высоте, которую можно перепрыгнуть**. Игрок обязан
  **грамотно перепрыгивать** их на `W`. Шары должны быть ритмичной последовательностью
  (2–4 шара с интервалом, иногда «двойной» с малым зазором), чтобы это был челлендж на тайминг.
  **Ирония:** Сэм тоже не хочет получить своим оружием — он **автоматически подпрыгивает**,
  когда шар подлетает к нему (визуально: приседает и прыгает, шар проходит под ним). Сделай
  это смешно: он подпрыгивает с недовольным лицом и репликой изредка («Мои же шары!»).
  Реализуй как физику: у шаров скорость, отскок от стен, урон при касании игрока.
- **«Выпайка ОЗУ»** — лазер по вертикали с телеграфом (уже есть, усилить: 0.9 с прицела,
  потом луч).
- **«Призыв инвестора»** — с неба падает значок `$` (или монета) в случайное место с тенью-
  маркером на полу; попадание — урон по площади.
- **«Апдейт модели»** — Сэм ненадолго становится полупрозрачным и телепортируется на
  случайную позицию (уклонение от спецприёма игрока).
- **«Серверный шквал»** — в фазе 3 Сэм вызывает 3 маленькие стойки, падающие по очереди
  с предупреждающими маркерами.

### 2.3. Обязательно сохранить
- Скриптовую подлянку с H100 и 9999 урона в раунде 1 (это сюжет).
- Механику «ЖМИ ПРОБЕЛ ДЛЯ УВОРОТА» и фаталити во втором раунде.
- BSOD, экран победы, уведомление, экран A+G+I, службу-наблюдателя.
- Работу в оверлее поверх рабочего стола (скриншот десктопа + полупрозрачный слой).
- `Esc` / `Ctrl+Q`.
- Procedural-ассеты: если добавляешь спрайты (шары, тени, эффекты) — **рисуй их кодом**
  (pygame.draw / PIL) в `tools/build_assets.py`, не тяни из сети.

## 3. Технические требования

- Не добавляй новых зависимостей, кроме уже используемых. Никакой сети в рантайме.
- Держи 60 FPS; пулы частиц — с лимитом, без утечек; списки снарядов чистить каждый кадр.
- Всё, что пикается с клавиатуры — через `pygame.key.get_pressed()` в `update`, события —
  через `events` (не смешивай).
- Каждая новая атака — отдельный метод с понятным именем и состоянием в словаре бойца.
- Баланс вынеси в константы вверху класса/файла, чтобы легко править.
- Комментарии — по-русски, коротко, по делу.
- Ничего не ломай в `--watch`, `--install`, `--uninstall`, `--selftest`.
  `python main.py --selftest` должен по-прежнему проходить (он рисует все экраны в
  dummy-режиме и пишет лог).
